# Georgia Food Access ETL Project

This project builds an ETL pipeline to clean, validate, and analyze USDA Food Access data for Georgia census tracts.

## Key Features
- Geographic standardization (CensusTract, FIPS)
- Data validation (uniqueness, completeness, consistency)
- Feature engineering (SNAP_rate, NoVehicle_rate)
- Analysis of edge cases (group quarters, small populations)
